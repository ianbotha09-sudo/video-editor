# ClipForge Free Video Editor

A free, mobile-first browser video editor designed to run from GitHub Pages.

## Included
- Multiple videos and photos
- Reordering and deleting clips
- Trim start/end per clip
- Text overlay
- Speed controls
- Filters
- Music track
- 16:9, 9:16 and 1:1 formats
- Local project settings
- WebM export in supported browsers
- No account, paid service, watermark or server upload

## Free hosting
Upload `index.html`, `manifest.webmanifest` and `sw.js` to a public GitHub repository and enable GitHub Pages.

## Important
Export support depends on the browser. Chrome on Android is the recommended browser. Media is processed locally in the browser.
